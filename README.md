# LB Solar Website V3

Multi-page Next.js site for LB Solar Engineering & Consultancy.

## Included pages
- Home
- About
- Services
- Projects
- Blog (`/blog`)
- Career
- Enquiry
- Contact

Legacy routes redirect:
- `/technical-studies` → `/blog`
- `/lb-solar-ai` and `/ai` → `/`

## Develop

```powershell
npm install
npm run build
npm run dev
```

Open `http://localhost:3000`.
